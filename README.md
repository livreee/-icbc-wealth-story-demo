# -icbc-wealth-story-demo
是一款嵌入工商银行手机银行、面向年轻客群的游戏化金融健康陪伴产品。它把“理财入门”设计成一部21天的互动人生剧本：用户开场选择一条与自己生活目标相符的剧情线（装修小家、迎接宝宝、梦想旅行、自由Gap、第一次独居），之后每天用约5分钟完成一个存钱理财小任务，开启一个盲盒宝箱，推动剧情和养成角色向前，21天后完成第一次完整的“看清钱—攒下钱—守住钱”的理财闭环。 本产品的核心判断是：年轻人不是不想理财，而是被术语、门槛和孤独感挡在了门外。我们不做理财课程，也不直接推销产品，而是用“人生故事+熟人陪伴+真实账户”的方式，让零起点用户愿意来、留得住、最终把钱和习惯留在工行。
